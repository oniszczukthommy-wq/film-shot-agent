## 本轮发现并修掉的问题

1. **续集评分串片**：《沙丘》和《沙丘2》的 TMDB 评分互相挂到对方卡片上。
   - 修法：片名匹配时数字必须一致（`沙丘` ≠ `沙丘2`），评分事实也要过片名校验。
   - 测试：`test_sequel_ratings_do_not_cross_attach`。
2. **“最近”没有今天日期**：第一轮会推荐更早的旧片。
   - 修法：system prompt 注入 `当前日期`，明确以当天为准。
3. **模型编占位片名**：出现“未确认片名（豆瓣讨论提及…）”卡片。
   - 修法：过滤“未确认片名/未知片名/待确认片名”这类占位标题。
4. **模型漏调 `movie_facts` 时评分空着**：台词题命中《银翼杀手》但没评分。
   - 修法：答案生成后，对缺评分/渠道的候选做一次确定性 TMDB 补查，片名必须匹配。
   - 测试：`test_enrichment_adds_a_tmdb_rating_without_the_composer`。
5. **豆瓣分只能靠模型手抄**：同一条《繁花》，有时卡片有豆瓣分，有时没有。
   - 修法：从豆瓣/IMDb 搜索摘要里用正则抽分数，写进评分事实；同一来源只留一张卡，优先官方条目页。
   - 测试：`test_extract_score_from_snippets`、`test_merge_ratings_prefers_item_page_and_one_per_source`。
6. **trace 里 `movie_facts` 显示 0 条**：有数据但计数为 0。
   - 修法：计数把 `ratings / reviews / tmdb_reviews` 一起算。

## 仍然存在的边界

- **豆瓣分不是实时分**：只有搜索摘要里带数字时才能显示；同一条目可能看到 8.1/8.4/8.6 多个说法，答案会明确说不一致。
- **免费渠道只能标“可能免费/需确认”**：TMDB 在中国区经常没有观看数据，渠道来自搜索结果；只有 TMDB 明确 `free` 才写“免费”。
- **模糊画面只给候选**：没有全电影镜头库，第 6 题这类问题本来就不存在唯一答案。
- **搜索兜底慢且会限流**：DuckDuckGo 被限流后熔断 10 分钟，转 360；单次 20 秒左右。配 Tavily Key 可降到 2–5 秒。
- **未上映影片可能出现在推荐里**：第 1 题把《沙丘3》作为“值得留意”列出，但没有评分和渠道，不影响“现在能看”的结论。
