# 问片第 3 轮 · 照着做清单

## 本地打开

1. 在项目文件夹执行：
   ```bash
   uv run uvicorn film_shot_agent.main:app --app-dir src --port 8000
   ```
2. 浏览器打开 <http://localhost:8000/chat>。
3. 在底部输入框粘贴：
   `“说好的一辈子，差一年一个月一天一个时辰，都不算一辈子”是哪部电影的台词？`
4. 等 20–30 秒，看到：
   - 片名《霸王别姬》+ 1993 + 海报；
   - 豆瓣 9.6（标注"33台词收录的豆瓣分，非实时抓取"）；
   - 台词、英文原句、中文翻译；
   - 约 01:01:36；
   - 「去 33 台词播放/截图」按钮；
   - 6 个平台搜索入口。

## 再试三条

- `“希望是美好的，也许是人间至善”出自哪部电影？` → 《肖申克的救赎》02:15:48
- `I am gonna make him an offer he cannot refuse — which movie is this from?` → 《教父》00:24:46
- `“月亮今晚很圆，像你家的锅盖”出自哪部电影？` → 应该明确说"没查到"，不出卡片

## 看到的算对

- 有片名、有海报、有时间点、有原句/翻译、有来源按钮；
- 没有把博客里的分数写成实时豆瓣分；
- 查不到时直接说没查到，不硬猜。
