# 线上演示 · 照着做清单

**网址**：https://film-shot-agent.onrender.com/

- 首页就是对话框。
- 镜头库在 https://film-shot-agent.onrender.com/library。
- 旧链接 `/ask` 会自动跳回首页。

## 打开后先看三件事

1. 页面标题是「一句话，找到那部片。」，底部有输入框。
2. 点一个推荐问题，等 10–30 秒出卡片。
3. 卡片上有海报、片名、年份、豆瓣分、台词、时间点、来源按钮。

## 推荐演示顺序

1. `“说好的一辈子，差一年一个月一天一个时辰，都不算一辈子”是哪部电影的台词？`
   - 预期：《霸王别姬》1993；约 01:01:36；豆瓣 9.6；海报；B站片段。
2. `“希望是美好的，也许是人间至善”出自哪部电影？`
   - 预期：《肖申克的救赎》1994；约 02:15:48；豆瓣 9.7；海报；点「看前后文」能看到上下句。
3. `I am gonna make him an offer he cannot refuse — which movie is this from?`
   - 预期：《教父》1972；约 00:24:46；豆瓣 9.3；原句 + 中文翻译。
4. 想展示“不编造”时：
   `“月亮今晚很圆，像你家的锅盖”出自哪部电影？`
   - 预期：明确说没查到，不出卡片。

## 不要做

- 不要点镜头库里的「播放」「导出」：线上只带索引和缩略图，没有影片本体。
- 不要把链接发到大群或社交平台：没有登录，拿到的人都会消耗模型/搜索额度。
- 海报如果偶尔不显示，是 33台词/ TMDB 图床波动；卡片其余字段仍然可用。

## 如果第一次打开很慢

Render 免费实例有冷启动，通常 30–50 秒；GitHub Actions 每 5 分钟保活。等页面出来即可，不是坏了。
