# 面试讲解

## 90 秒演示脚本

**开场（10 秒）**

> 这是一个影视镜头检索助理。片库是两部 CC BY 授权的开源电影，244 个镜头全部由 ffmpeg 自动抽帧、
> 算出调色板之后建索引的。我先演示它最核心的一件事：用一句话找画面。

**第一段：一句话检索（25 秒）**

在输入框敲「找冷色调、暗一点的镜头」→ 回车。

> 注意这里没有大模型参与。规则把"冷色调、暗一点"映射成两个筛选参数，
> 下面这行 trace 就是证据：调了 `search_shots`，参数是 color_temp=cool、brightness=dark，
> 返回 31 条，耗时 1 毫秒。模型不该决定返回哪些镜头，它只适合做意图标签。

**第二段：URL 就是查询（15 秒）**

点左上「复制查询链接」，粘贴到新标签打开。

> 检索状态全部编码在路径里，`/browse/color_temp/cool/brightness/dark`。
> 任何一次检索都能发出去复现，这是刻意的设计——参考的两个产品都是这么做的。

**第三段：分面计数（15 秒）**

看左侧。

> 每个筛选项右边的数字是"如果选它，还剩多少"。而且算这个数字的时候排除了这一维度自己，
> 所以你才能在同一个维度里换选项，而不是把自己筛空。

**第四段：台词 + 画面联动（20 秒）**

切到「台词」，搜 `robot`。

> 每条命中都带前一句、后一句、中文翻译，还有命中高亮。关键是左边这张小图——
> 这是说出这句话时画面上的那一帧，用时间轴自动对齐的，没有人工标注。

**第五段：从台词跳进画面（20 秒）**

在任意一条台词后面点「▶ 从这句开始播」。

> 播放器直接跳到了这句话说出来的时间点。播放走 Range 请求，所以进度条能拖、不用等整片加载。
> J / K / L 逐帧和播放暂停，和剪辑软件的键位一致。

**收尾（10 秒）**

关掉播放器，点「加入板」→ 切参考板 → 点「导出拼图」或「打印 PDF」。

> 切片和拼图都是本地 ffmpeg 现做的，5 档 GIF、A4 横板带署名。素材是 CC BY 授权的，所以切和发都没问题。

## 可能被追问的问题

### 「这个人你是不是只是抄了两个网站？」

> 反推过它们的实现：一个是路径式查询 + 服务端渲染 HTML 片段，一个是 22 个人工筛选维度 +
> 调色板检索。抄的是**机制**，不是代码。而且有几样我明确没抄，理由写在 `docs/设计取舍.md` 里：
> 人工标注维度（没团队，硬做就是空字段）、下载第三方视频（法律风险且演示不需要）、
> 账号和分享外链（单人演示用不上，且整板截图外链有版权风险）。

### 「为什么不用大模型？」

> 演示要可复现，模型一抽风就翻车。更重要的是**这个场景不需要**：用户说的是"冷色调、暗一点"，
> 规则完全覆盖；真要接模型，正确的接法是让它输出受约束的意图标签，而不是让它挑镜头。
> 现在的 trace 面板反而更好聊——每一步都可解释。

### 「244 个镜头太少了，规模上去了怎么办？」

> 两处会先坏：取色检索是"先 SQL 再 Python 过滤"，上万镜头要预建颜色索引表；
> 场景切分阈值是固定 0.35，快节奏片子会切太碎，得按片自动调。
> 剩下的是加索引就行：`(title_id, seq)`、`(color_temp, brightness_bucket)` 已经建了。

### 「筛选维度为什么只有 7 个？」

> 因为只做机器能算的。看过的那家竞品有 22 个维度，但那是标注团队喂出来的；
> 我没有标注团队，硬做会得到一排永远空着的字段，反而暴露"没想清楚"。
> 现在这 7 个 + 取色检索，每个都是满的，`/api/facets` 里点一下数字都对得上。
> 要补也清楚怎么补：跑一个视觉模型打标，写回 Shot 的新列，检索层不用动。

### 「档位阈值怎么定的？」

> 一开始写死（亮度 > 0.6 算亮调），结果 120 个镜头里 110 个被判成高对比——
> 电影本来就对比度高，固定阈值等于没筛。改成按本库三分位切，每个档位稳定 1/3。
> 代价是档位含义随库变化，所以库里同时存了原始浮点值。

### 「测试怎么保证？」

> 46 个测试，0.3 秒跑完，不联网、不需要 ffmpeg。媒体调用在测试里被替换掉，
> 测的是缓存命中、档位计算、路径编解码、分面计数这些真正属于业务的逻辑。
> `uv run ruff check .` 也是干净的。

### 「版权怎么处理的？」

> 素材是 Blender Foundation 的 CC BY 3.0 开源电影，允许切片和分发，页面上会带署名。
> 不做的事也写在 README 里：不下载未授权影视、不接第三方站点截图、不做 DRM/会员绕过。
