- 日期：2026-10-30
- 目的：回答"给一句台词，能不能找到是哪部电影"，并把结果做成可看的卡片。
- 配置：DeepSeek `deepseek-chat` + Tavily + TMDB + 33 台词字幕库（无 Key）。
- 入口：`/chat`（`/ask` 已 302 跳转到 `/chat`）。

## 这一轮加了什么

1. `search_subtitles`：直接查 33 台词的字幕索引。
   - `langType=0`：英文/西方影视字幕，中文翻译也在里面。
   - `langType=1`：中文字幕（《霸王别姬》《独自等待》等）。
2. 台词题由确定性代码先调一次字幕库，不依赖模型"记得调工具"。
3. 字幕库命中后，卡片自动补：精确时间点、原句、中文翻译、前后句、海报、收录的豆瓣分、33 台词跳转。
4. 过滤用"最长连续命中"，`至善` 这种两字重合不会把《雨人》误当成答案。
5. 字幕库失败或没命中时，回落到 Tavily + 本地片库，并在 caveat 里说明。

## 仍然存在的边界

- **中文片依赖中文字幕索引**：`langType=1` 能查到《霸王别姬》，但不是所有中文片都有字幕条目；查不到时只给片名和联网候选，不编时间点。
- **一句话可能跨多条字幕**：字幕库按单条字幕返回，时间点是这句开始的时间；同一句的后半句可能在下一条（相差几秒）。
- **系列片会命中衍生剧**：例如"愿原力与你同在"先命中《克隆人战争》，1977 年原片没有字幕条目时无法给原片时间点。
- **33 台词没有官方 API**：用的是它网页自己的搜索接口，可能变、可能限流。失败会自动回落到 Tavily + 本地片库；只做个人研究，不批量抓取。
- **豆瓣分不是实时分**：来自 33 台词收录的条目数据，卡片上写明"非实时抓取"。
