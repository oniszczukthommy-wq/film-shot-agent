# 33 台词（33tc）播放链路拆解

> 目的：看它"台词 → 播放/截图/剪切"到底怎么做的，我们哪些能复用、哪些不能。
> 范围：只做技术研究，不绕过登录、不批量抓取、不把版权内容搬进自己的仓库。

## 1. 搜索

`POST https://33-api.agilestudio.cn/api/v2/search`

请求体：

```json
{
  "subtitleKeyword": "希望是美好的",
  "langType": 0,
  "addAiSubFlag": 0,
  "exactFlag": 0,
  "phraseMode": 0,
  "indexType": 0,
  "page": 1,
  "limit": 20
}
```

- `langType=0`：英文/西方影视字幕（中文翻译也在这份里）。
- `langType=1`：中文字幕（《霸王别姬》等中文片在这里）。
- 签名：query 参数按 key 排序，拼成 `k=v,`，取 MD5 放 `X-Signature`；`_ts = Date.now() - 9999`。body 不参与签名。
- 返回每条字幕带 `video`：片名、`video.url`（HLS m3u8 或 YouTube 链接）、海报、豆瓣分、`startTime/endTime`、前后字幕。

## 2. 播放（预览）

前端用 **video.js** 的 `RangeVideoPlayer` 组件：

```text
url            = subtitle.video.url          // application/x-mpegURL (HLS) 或 video/youtube
source-type    = /youtube/ ? "video/youtube" : "application/x-mpegURL"
subtitle-url   = /video/vtt-subtitle/{videoId}-{startMs}-{endMs}.vtt
start-time     = 字幕开始前最多 10 秒
end-time       = 字幕结束后最多 10 秒
controls       = false
autoplay       = true
```

播放器初始化时设置 video.js 的 `start` / `end`，并在 `timeupdate` 里强制边界：

- 当前时间 < start → `seek(start)`
- 当前时间 > end → `seek(start)`，loop 时继续播，否则暂停
- 字幕用原生 `<track kind="captions">` 加载 VTT

预览按钮需要登录：未登录点「预览」会弹登录框，不是接口层面的公开能力。

## 3. 云截图

`GET /video/snapshot?videoId={id}&time={毫秒}&original=false`

- 前端先暂停视频，取 `currentTime()`，乘 1000 传给接口。
- 返回 `{url, subtitleList, time}`，`url` 是服务端截好的图。
- 需要登录 + 积分，前端会先调 `/integral/cal-cost` 算积分。

## 4. 云剪切

`POST /cut/cut-video-v2`

```json
{ "videoId": 914, "startTime": 221023, "endTime": 231023 }
```

- 时间单位是毫秒，来自前端滑块。
- 需要登录 + 积分；提交后在「剪切任务」里异步生成，文件只保留约 3 天。

## 5. 字幕接口

| 接口 | 是否需要登录 | 用途 |
| --- | --- | --- |
| `GET /video/get-subtitle/{videoId}.vtt` | 否 | 整部片的 VTT 字幕 |
| `GET /video/vtt-subtitle/{videoId}-{startMs}-{endMs}.vtt` | 否 | 指定时间窗口的 VTT |
| `GET /video/get-more-subtitle?subtitleId=...` | 否 | 某条字幕前后的 10 条 |
| `GET /video/get-video-info?videoId=...` | 是 | 视频详情、播放地址 |
| `GET /video/snapshot` | 是 | 云截图 |
| `POST /cut/cut-video-v2` | 是 | 云剪切 |

## 6. 我们复用了什么

- **搜索 + 中/英两个字幕索引**：已接进 `adapters/thirtythree.py`。
- **字幕前后文**：已接 `get-more-subtitle`，在卡片点「看前后文」弹出窗口，命中行高亮。
- **时间点 + 前后 10 秒窗口**：已经用这个规则决定卡片显示哪一条字幕。

## 7. 我们没直接复用什么（以及为什么）

| 能力 | 不直接接的原因 |
| --- | --- |
| 内嵌播放 m3u8 | 33台词的视频 CDN 在开发机不可达；更关键的是，预览本身要求登录，直接拿 m3u8 播放等于绕过它的登录和积分，也会热链版权内容 |
| 云截图 `/video/snapshot` | 需要登录 + 积分，返回的是它服务端生成的图；不适合作为我们的公共接口 |
| 云剪切 `/cut/cut-video-v2` | 同上，且任务异步、文件只留 3 天 |
| 整部片 VTT | 可以做，但会把字幕全文落到我们的服务里，版权和存储都要重新评估 |

## 8. 如果一定要站内播放

两条合法路径：

1. **自有/授权片源**：把 mp4/HLS 放自己的对象存储，前端用 video.js + HLS，按同一套 `start/end + VTT` 逻辑播放。我们现有的镜头库已经是这个模式（本地 mp4 + Range + ffmpeg 切片），可以直接复用。
2. **公共领域/CC 片源**：例如 Internet Archive 的公版电影，拿它的直链播放，不需要绕过任何登录。

对 33台词里的第三方电影，当前产品保持「精确时间点 + 在 33 台词看这一句」的跳转，不内嵌播放。
