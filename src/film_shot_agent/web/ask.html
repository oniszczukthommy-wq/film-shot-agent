01

找片，免费优先

按你的口味给候选，先列合法免费渠道，再列会员和付费。所有链接都能点回平台。

02

查口碑，来源透明

TMDB / IMDb / 烂番茄 / 豆瓣搜索摘要并排给你，标清哪个是分数、哪个是摘要。

03

认镜头，只给候选

描述一个模糊画面，给 1–3 个候选和证据。证据弱会直说，不硬猜一个答案。

04

找台词，先查本地

本地授权片库能精确到时间点；全网台词给片名、角色和出处链接。

这是研究型助理：它会联网查资料，再把证据整理成答案。评分和渠道会变，点开来源确认。
